# ubitofu 0.10 Single-Cutover Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace ubitofu's current reconciliation pipeline with one tested
three-way architecture, release it as 0.10.0, then replace the downstream
Ansible shell policy in one cutover.

**Architecture:** Controller, OpenTofu, and HCL adapters produce immutable
snapshots for a pure planner. One renderer builds every candidate in memory.
Wet reconcile commits those candidates through one recoverable transaction.
`reconcile --dry-run` returns the same plan and candidates without starting the
transaction. The public CLI switches once after the complete replacement is
ready, and the old implementation is deleted in that same commit.

**Tech Stack:** Python 3.11+, OpenTofu 1.12.x, tree-sitter 0.26.0,
tree-sitter-hcl 1.2.0, httpx, frozen dataclasses, pytest, Hypothesis, Ruff,
strict mypy, mutmut, wheel/sdist packaging tests.

## Global Constraints

- Preserve the plan-only product boundary. ubitofu never writes the controller,
  applies a plan, mutates state, backs up a backend, commits to Git, opens a PR,
  detects a CI vendor, schedules work, or sends notifications.
- Do not add a legacy writer, alternate source index, shadow command, feature
  flag, compatibility alias, dual-run consumer, or intermediate public release.
- Development uses small commits and direct module tests. Until Task 10, existing
  public commands remain the only production entry points and new modules are
  exercised through tests, not a second CLI.
- The Task 10 switch changes every public command and deletes every replaced path
  in one commit. Do not tag or package a partial state as a release.
- `reconcile` and `reconcile --dry-run` must collect one equivalent immutable
  snapshot and derive identical plans, candidate bytes, decisions, changed
  paths, candidate digests, and blocking outcomes.
- Dry-run may create private, short-lived plan artifacts under `.ubitofu/tmp`.
  It must not prepare a file transaction or change a destination HCL byte.
- Same-field HCL and controller changes block the complete reconcile. Neither
  authoring surface wins automatically.
- Computed and unknown values do not become drift. Expanded instances never
  delete a shared source block. Managed-device creation remains forbidden so
  adoption stays in the controller UI.
- Use complete OpenTofu addresses. Module, indexed, data, and deposed addresses
  remain visible but block source edits unless one unambiguous source block owns
  the change.
- tree-sitter is the only production index for operator-owned native HCL.
  python-hcl2 remains only for ubitofu-owned generation where currently needed.
- JSON configuration participates in precedence and discovery but remains
  read-only. Edit-required JSON drift blocks reconciliation.
- Hold one advisory workdir lock from startup recovery through snapshot,
  planning, rendering, optional commit, reporting, and private artifact cleanup.
- The transaction protects an administrator-owned worktree from crashes,
  concurrent ubitofu processes, stale snapshots, path mistakes, and external
  edits observed by the final per-file recheck. External writes during the
  replacement window and hostile syscall races are out of scope, so
  directory-FD traversal is not required.
- Preserve POSIX mode, uid, and gid. Require the worktree owner to own every
  edited file. Version 0.10 refuses files with ACLs, extended attributes, or
  file flags, and fails closed when the platform metadata adapter cannot prove
  their absence.
- Supported runtime operating systems are macOS and Linux. Windows is not part
  of the 0.10 support contract because the workdir lock uses `fcntl`.
- Model planner and transaction phases with frozen values and enums. Do not add
  a state-machine framework.
- Normal diagnostics and receipts contain bounded allowlisted context only.
  Never emit credentials, raw controller bodies, provider stderr, HCL values,
  URL userinfo, ANSI controls, or unrelated absolute paths.
- All runtime files use the repository SPDX/copyright header. Test fixtures use
  only the established synthetic vocabulary and contain no private identifiers.
- Each task starts with a failing focused test, records the expected failure,
  implements the smallest complete contract, reruns focused tests, Ruff and
  mypy, then commits locally in repository style.
- Keep the existing staged-validation proof and decision record as evidence.
  Do not promote its dependency-cache reconstruction or OS sandbox into runtime.

## File Map

New focused modules:

- `errors.py`: typed safe operational errors and bounded rendering.
- `values.py`: the one recursively immutable JSON-compatible value model.
- `runtime.py`: workdir locking and private per-command artifact ownership.
- `tofu_json.py`: strict OpenTofu JSON headers and immutable used-field models.
- `hcl_index.py`: strict tree-sitter index over original bytes.
- `hcl_patches.py`: verified, non-overlapping byte patch application.
- `module_index.py`: one effective `.tf`/`.tofu`/JSON source set and precedence.
- `reconcile_model.py`: immutable addresses, observations, decisions, and plans.
- `reconcile_snapshot.py`: all external reads and normalization before planning.
- `controller_projection.py`: raw controller records to comparable provider paths.
- `reconcile_planner.py`: total pure three-way decision function.
- `reconcile_renderer.py`: edit intents to complete in-memory candidates.
- `file_transaction.py`: prepare, commit, rollback, recovery, and quarantine.
- `file_metadata.py`: fail-closed macOS/Linux metadata inspection.
- `outcomes.py`: command-independent outcomes, receipts, and human/JSON output.
- `plan_check.py`: point-in-time authorization of one supplied saved plan.
- `inspect.py`: provider/controller coverage interpretation.
- `health.py`: normalized health snapshots and delta comparison.
- `generate.py`: one immutable generation snapshot and complete candidate preview.

Retained modules:

- `controller.py` and `tofu_runner.py` remain the only external I/O adapters.
- `enumerator.py`, `cleaner.py`, `hcl_writer.py`, and `import_emitter.py` remain
  internal generation helpers.
- `pipeline.py` becomes the small composition root.
- `cli.py` owns argument parsing, config overrides, exit mapping, and dispatch.

Deleted or absorbed at the Task 10 switch:

- `hcl_surgeon.py` handwritten discovery and editing.
- `reporter.py` parallel string-first outcome classification.
- old `pipeline.py` classification and per-file write helpers.
- public `enumerate`, `verify`, and `reconcile --check` command paths.
