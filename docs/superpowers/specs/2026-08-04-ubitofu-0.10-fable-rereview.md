## Architecture judgment

Fable found the overall architecture sound. The product boundary remains a
small, plan-only Unix tool; Ansible retains apply, Git, scheduling, secrets, and
notifications. Python remains appropriate, tree-sitter remains limited to
structural indexing and byte anchors, and OpenTofu remains the HCL semantic
oracle. The immutable snapshot, planner, preview, transaction, and outcome
boundaries are coherent. The big-bang 0.10 cutover remains justified by the
full verification gate and the absence of a legacy or dual-run path.

The generation scaffold is also the right bounded response to OpenTofu's need
for a physical root-module import block. Its hard-link and durable-manifest
protocol is proportionate because the simpler private-root and direct-schema
approaches failed their semantic spikes. The exclusivity exception is correctly
confined to initial generation and does not weaken `reconcile --dry-run`.

## Important findings

### 1. Secret drift needs an explicit product policy

The design promises that conflicting HCL and controller changes do not silently
choose a winner, while controller projection explicitly excludes sensitive
paths and the planner can classify them as `SECRET_SUPPRESSED`. The documents do
not say whether secret paths are part of bidirectional reconciliation, whether a
UI secret change can be detected, or what `check` authorizes for them.

The fix must state an honest, testable policy in the product boundary, semantic
model, Task 3 decision table, and Task 7 saved-plan checks. It must not retain or
emit controller secret values. If a provider/controller surface cannot expose a
comparable secret observation, the docs must say so and explain the operational
consequence rather than implying full conflict detection.

### 2. The reserved scaffold path must be impossible as durable output

`ubitofu-imports.tf` is reserved for the generation-only root scaffold, but the
design does not explicitly prohibit it as a renderer candidate or transaction
destination. A durable file at that name would prevent later generation and be
indistinguishable from unmanifested interference.

The fix must reserve the path at the renderer and shared transaction boundary,
test both rejections, keep an occupied unmanifested path distinct from exact
recoverable crash residue, ignore the transient name in Git, and keep the
scaffold manifest protocol explicitly versioned.

## Minor findings for the final cleanup

- State wet/dry parity as applying to equivalent snapshots.
- Align the claim that `check` runs immediately before apply with the actual
  backup, digest, and health-snapshot ordering, or reorder those steps.
- Align the design and plan rules for whether `--output` may create a new file
  and which owner identity it checks.
- Declare the bounded remaining use of `python-hcl2` and its removal criterion.
- Document the assumption that active source has not changed since the saved
  plan, or warn when it cannot be tied to the plan-time configuration.
- Classify a UI capture targeting a non-literal expression as typed attention
  instead of a generic renderer failure.
- Name the exact blocking file and extended attribute in fail-closed metadata
  diagnostics, and document that operator-facing limitation.

No Critical finding was reported. Fable's GO condition is closure of both
Important findings; the Minor findings remain final implementation-review
items unless one proves to affect correctness.
